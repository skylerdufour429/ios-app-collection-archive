# iOS App Collection Archive

A static web archive for documenting legacy iOS app metadata without shipping proprietary binaries.

## Included
- HTML/CSS/JS frontend
- JSON-backed app catalog
- GitHub Pages-ready structure
- VS Code Dev Container configuration
- Lightweight validation script for catalog integrity

## Local preview
From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.
